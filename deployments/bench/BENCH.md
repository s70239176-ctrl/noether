# Noether live benchmark

Real testnets: Base Sepolia, Unichain Sepolia and Reactive Lasna, on Noether's Hyperlane warp route. Runs from 2026-11-25T13:51:51.616Z to 2026-11-25T15:00:55.180Z. Generated by `app/scripts/bench.mjs` (raw rows: [runs.jsonl](runs.jsonl)) and summarised by `app/scripts/bench-summary.mjs`.

Each cycle sends 1 or 2 honest 100 dUSD transfers, then a **forged mint** through Hyperlane's real Unichain Mailbox with the route's compromised relayer key, then a **copycat** forged message, then a governance resolve back to NORMAL.

Errored cycles failed in a public RPC call or in the resolve step, never in detection. Each attack's data was recorded before its resolve. One errored cycle's honest transfers were rejected with `ISM verification failed` because the previous resolve had timed out, so the route was still frozen: the freeze holding, not a false positive.
